§1 ความสม่ำเสมอรายหลัก (Marginal uniformity)

§2 การกระจายตัวร่วม (Joint distribution)

§6 Backtest: กลยุทธ์เลือกเลขเทียบกับการสุ่ม (รวมกลยุทธ์อิงสัดส่วนทองคำ)

ทุกกลยุทธ์รันแบบ walk-forward (เห็นเฉพาะข้อมูลก่อนหน้า ไม่มี lookahead) เทียบกับ baseline สุ่มและค่าคาดหวังทางทฤษฎี

Backtest ตามขนาดตัวอย่างย่อย (10–50 งวดล่าสุด) — เช็คว่าผลคงที่ไหมในช่วงข้อมูลน้อย

รันซ้ำเฉพาะ N งวดล่าสุด (N = 10, 15, 20, ..., 50) แยกจาก backtest หลักด้านบนซึ่งใช้ข้อมูลทั้งหมด — ที่ขนาดตัวอย่างเล็กขนาดนี้ พลังทางสถิติต่ำมาก โอกาสถูก/ไม่ถูกเพียง 1-2 ครั้งสามารถทำให้ ROI กระโดดขึ้นลงแรงได้ (เช่น hit 1 ครั้งจาก 7 ครั้ง = ROI +200%) — นี่คือตัวอย่างจริงว่าทำไมต้องใช้ ข้อมูลอย่างน้อย 35+ งวดถึงจะสรุปอะไรได้อย่างมั่นใจ ไม่ใช่หลักฐานว่ากลยุทธ์นั้นใช้ได้จริง

§7 จำนวนเลขที่แทง (k) และอัตราจ่ายจริงเทียบกับอัตราจ่ายเป็นธรรม

คำถาม: ถ้าแทงหลายเลขต่องวดแทนที่จะแทงเลขเดียว ผลเปลี่ยนไหม? และอัตราจ่ายจริงกับอัตราจ่าย "เป็นธรรม" (ไม่มี house edge) ต่างกันแค่ไหน?

ข้อควรระวัง
  • 3 ตัว / 2 ตัว ล้วนมาจากเลข 4 ตัวชุดเดียวกัน (ตัดหลักหน้าออกตามลำดับ) ไม่ใช่การสุ่มอิสระแยกกัน
  • ผลที่มีนัยสำคัญเพียงจุดเดียวจากหลายการทดสอบ อาจเป็นผลจาก multiple testing ไม่ใช่ความไม่สุ่มจริง
  • Backtest ที่ไม่พบกลยุทธ์ใดเอาชนะการสุ่มได้ สอดคล้องกับทฤษฎีความน่าจะเป็นสำหรับการสุ่มที่เป็นอิสระ
  • กลยุทธ์อิงสัดส่วนทองคำ (golden ratio sequence) เป็นเทคนิคทางคณิตศาสตร์จริง (ใช้ในสุ่มตัวอย่างแบบ low-discrepancy) แต่ไม่มีความเกี่ยวข้องกับการทำนายการสุ่มอิสระ — ผลการทดสอบในหน้านี้คือหลักฐานเชิงประจักษ์ของข้อจำกัดนี้
